# 개인 개발 블로그 MVP PRD

## 핵심 정보

**목적**: Notion을 CMS로 활용하여 글 작성과 발행을 Notion 워크플로우 안에서 해결하고, 별도 관리 없이 블로그에 자동 반영되는 개인 기술 블로그 구축
**사용자**: 기술 글을 Notion에서 작성하고 블로그로 공개하고 싶은 1인 개발자

---

## 사용자 여정

```
1. 홈 페이지 (/)
   └─ 최근 글 목록 확인
      ↓ 카테고리 버튼 클릭
      └─> 카테고리 페이지로 이동
      ↓ 검색 입력
      └─> 검색 결과 (홈 페이지 내 필터링)
      ↓ 글 카드 클릭

2. 글 상세 페이지 (/posts/[slug])
   └─ Notion 페이지 본문 렌더링
      ↓ 뒤로가기 / 헤더 홈 클릭

3. 카테고리 페이지 (/category/[name])
   └─ 해당 카테고리 글 목록 확인
      ↓ 글 카드 클릭
      └─> 글 상세 페이지로 이동
```

## 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|---------------|-------------|
| **F001** | Notion 글 목록 조회 | Notion DB에서 Status=발행됨인 글을 발행일 내림차순으로 조회 | 블로그의 핵심 콘텐츠 진입점 | 홈 페이지, 카테고리 페이지 |
| **F002** | 글 상세 표시 | Notion 페이지 블록을 HTML로 변환하여 렌더링 | 블로그의 핵심 가치 — 글 읽기 | 글 상세 페이지 |
| **F003** | 카테고리 필터링 | Category 필드 값으로 글 목록을 필터링 | 콘텐츠 탐색 기본 수단 | 홈 페이지, 카테고리 페이지 |
| **F004** | 키워드 검색 | 글 제목 기준 클라이언트 사이드 검색 | 글이 많아질수록 탐색 필수 | 홈 페이지 |

### 2. MVP 필수 지원 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|---------------|-------------|
| **F010** | SEO 메타데이터 | 페이지별 title, description, OG 태그 자동 생성 | 검색 유입 및 공유 품질 | 홈 페이지, 글 상세 페이지, 카테고리 페이지 |
| **F011** | ISR 캐싱 | revalidate 설정으로 빌드 없이 최신 글 반영 | Notion 변경사항 자동 반영 | 홈 페이지, 글 상세 페이지, 카테고리 페이지 |
| **F012** | 다크모드 | next-themes 기반 라이트/다크 토글 | 개발 블로그 독자층 기본 기대값 | 공통 레이아웃 (모든 페이지) |
| **F013** | 반응형 레이아웃 | 모바일/태블릿/데스크탑 브레이크포인트에 따라 그리드와 타이포그래피 조정 | 모바일 비율이 높은 독자층 접근성 보장 | 공통 레이아웃 (모든 페이지) |

### 3. MVP 이후 기능 (제외)

- 댓글 시스템
- 뉴스레터 구독
- 태그별 필터링 (카테고리로 대체)
- RSS 피드
- 조회수 카운터
- 관련 글 추천

## 페이지별 상세 기능

### 홈 페이지

> **구현 기능:** `F001`, `F003`, `F004`, `F010`, `F011`, `F012`, `F013` | **메뉴 위치:** 헤더 로고 클릭 / 루트 경로 진입

| 항목 | 내용 |
|------|------|
| **역할** | 블로그 진입점 — 전체 발행 글을 최신순으로 보여주고 카테고리 필터 및 키워드 검색 제공 |
| **진입 경로** | 최초 접속, 헤더 로고 클릭, 카테고리 페이지에서 전체 선택 |
| **사용자 행동** | 글 목록 스크롤, 카테고리 버튼으로 필터링, 키워드 입력으로 검색, 글 카드 클릭으로 이동 |
| **주요 기능** | - Notion DB에서 Status=발행됨 글 목록 조회 (F001)<br>- 카테고리 버튼 탭으로 글 목록 필터링 (F003)<br>- 글 제목 기준 클라이언트 사이드 실시간 검색 (F004)<br>- 글 카드 컴포넌트: 제목, 카테고리 뱃지, 발행일, 태그 표시<br>- 페이지 title / description / OG 태그 설정 (F010)<br>- ISR revalidate 적용 (F011)<br>- 다크모드 토글 버튼 (F012)<br>- 모바일/태블릿/데스크탑 반응형 그리드 레이아웃 (F013) |
| **다음 이동** | 글 카드 클릭 → 글 상세 페이지, 카테고리 버튼 클릭 → 카테고리 페이지 |

### 글 상세 페이지

> **구현 기능:** `F002`, `F010`, `F011`, `F012`, `F013` | **메뉴 위치:** 홈 페이지 또는 카테고리 페이지의 글 카드 클릭

| 항목 | 내용 |
|------|------|
| **역할** | 개별 블로그 글의 본문을 Notion 블록 기반으로 렌더링하여 독자에게 제공 |
| **진입 경로** | 홈 페이지 글 카드 클릭, 카테고리 페이지 글 카드 클릭 |
| **사용자 행동** | 글 본문 읽기, 코드 블록 확인, 헤더 클릭으로 홈 복귀 |
| **주요 기능** | - Notion 페이지 블록(paragraph, heading, code, image, bulleted_list, numbered_list, quote) HTML 변환 렌더링 (F002)<br>- 글 제목, 카테고리, 태그, 발행일 메타정보 표시<br>- 코드 블록 신택스 하이라이팅<br>- 글별 title / description / OG 태그 자동 생성 (F010)<br>- ISR revalidate + generateStaticParams 적용 (F011)<br>- 다크모드 토글 버튼 (F012)<br>- 본문 최대 너비 제한 및 모바일 패딩 조정 (F013)<br>- **뒤로가기** 링크 |
| **다음 이동** | 헤더 로고 클릭 → 홈 페이지, 뒤로가기 → 이전 페이지 |

| **다음 이동** | 글 카드 클릭 → 글 상세 페이지, 헤더 로고 클릭 → 홈 페이지 |

## 데이터 모델

### Post (Notion DB 매핑)

| 필드 | 설명 | 타입/관계 |
|------|------|-----------|
| id | Notion 페이지 ID | UUID (Notion 제공) |
| title | 글 제목 (Notion Title 필드) | string |
| slug | URL용 식별자 (Notion 페이지 ID 기반) | string |
| category | 카테고리 (Notion select 필드) | string |
| tags | 태그 목록 (Notion multi_select 필드) | string[] |
| publishedAt | 발행일 (Notion date 필드) | string (ISO 8601) |
| status | 발행 상태 (초안 / 발행됨) | "draft" \| "published" |

### NotionBlock (글 본문 렌더링용)

| 필드 | 설명 | 타입/관계 |
|------|------|-----------|
| id | 블록 ID | UUID (Notion 제공) |
| type | 블록 타입 | string (paragraph, heading_1 등) |
| content | 블록 텍스트 내용 | RichText[] |
| children | 중첩 블록 | NotionBlock[] |

## 기술 스택 (최신 버전)

### 프론트엔드 프레임워크

- **Next.js 15** (App Router) — 서버 컴포넌트 기반 렌더링, ISR 지원
- **TypeScript 5.6+** — 타입 안전성 보장
- **React 19** — 최신 동시성 기능 및 서버 액션

### 스타일링 & UI

- **TailwindCSS v4** (설정 파일 없는 새 CSS 엔진) — 유틸리티 CSS
- **shadcn/ui** — 고품질 React 컴포넌트 (Badge, Card, Button 등)
- **Lucide React** — 아이콘 라이브러리

### CMS 연동

- **@notionhq/client** — Notion 공식 API 클라이언트
- **notion-to-md** (선택) — Notion 블록을 Markdown으로 변환
- **react-syntax-highlighter** — 코드 블록 신택스 하이라이팅

### 테마

- **next-themes** — 다크모드 토글 (F012 구현)

### 배포 & 호스팅

- **Vercel** — Next.js 15 최적화 배포 플랫폼, ISR 자동 지원
